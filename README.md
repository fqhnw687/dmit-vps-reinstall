## DMIT 重装系统：方法一，后台一键换 OS 镜像

这是最直接的方式，不需要懂命令行，进后台点几下就完成了。

### 操作步骤

1. **登录 DMIT 后台**：进入客户中心，点左侧导航的"服务"，找到你购买的 VPS，点进去进入详情页。

2. **关机**：重装系统之前必须先关机。在 VPS 详情页找到电源控制部分，点"关机"（Power Off），等状态变成 Stopped 再继续。

3. **找到重装系统入口**：DMIT 后台目前的 UI 是新版设计，重装系统的按钮一般在 VPS 详情页的"操作"或"管理"区域里，叫"Reinstall"或"重装系统"。

4. **选择 OS 镜像**：点进去之后会弹出一个系统选择列表，支持的镜像覆盖挺全的，包括：
   - Debian 系列（Debian 11、Debian 12 等）
   - Ubuntu 系列（20.04 LTS、22.04 LTS 等）
   - CentOS / AlmaLinux / Rocky Linux
   - 部分机型还支持 Windows Server（需额外确认）

5. **确认并执行**：选好目标系统，点确认，等待重装完成。正常情况下几分钟以内完成，完成后会邮件通知。

6. **下载新 SSH 密钥或重设密码**：重装后默认还是走 SSH 密钥登录。如果原来的密钥还在，直接用就好；如果密钥弄丢了，进后台重新生成并下载。

这是最省事的方式，系统是 DMIT 官方预置的镜像，装完直接能用。

## 一个必须知道的坑：DMIT 默认不支持密码登录 SSH

这是新用户最常卡住的地方。

DMIT 的 VPS 开通或重装之后，**默认只能用 SSH 密钥登录，不能用密码**。很多人习惯了用密码 SSH，进不去就以为系统有问题，其实是这个原因。

密钥文件的下载入口在 VPS 详情页的"SSH 金钥管理"里。第一次进入会自动提示下载，记得保存好——密钥只能下载一次，以后找不到就得重新生成了。

解压之后你会看到两个文件夹，用 `Private_key` 里面的 `id_rsa.pem` 文件：

- **Windows 用户**：用 XShell 或 MobaXterm，选"密钥认证"方式导入 .pem 文件登录
- **Mac / Linux 用户**：终端里直接执行 `ssh -i /path/to/id_rsa.pem root@你的IP`

如果确实需要密码登录，用密钥进去之后执行以下命令开启：

bash
passwd
sudo sed -i 's/^#\?PermitRootLogin.*/PermitRootLogin yes/g' /etc/ssh/sshd_config
sudo sed -i 's/^#\?PasswordAuthentication.*/PasswordAuthentication yes/g' /etc/ssh/sshd_config
sudo service sshd restart
reboot


重启之后就可以用密码 SSH 了。改完密码记得做一次完整的关机再开机，不然新密码不会生效。

## DMIT 重装系统：方法二，DD 脚本重装（想装官方镜像没有的系统时用这个）

后台的镜像列表够用，但如果你需要一个 DMIT 没有预置的版本，比如某个特定的 Debian 小版本，或者想装 Windows，就要走 DD 脚本的路子。

说实话这条路稍微麻烦一点，需要能先进到 VPS 的 SSH，然后跑脚本。

### 用 reinstall.sh 脚本（推荐）

目前口碑比较好的是 bin456789 写的 reinstall 脚本，走官方 ISO 安装，不是第三方 DD 镜像，安全性更高。

进入 VPS 之后执行：

bash
curl -O https://raw.githubusercontent.com/bin456789/reinstall/main/reinstall.sh


然后按需选择：

bash
# 重装 Debian 12
bash reinstall.sh debian-12

# 重装 Ubuntu 22.04
bash reinstall.sh ubuntu-22.04

# 重装 CentOS 9
bash reinstall.sh centos-9


执行后脚本会自动下载 ISO、配置网络、完成安装，等几分钟到十几分钟不等（取决于网速），装完之后重启就好。

安装 Windows 也走这个脚本，需要额外提供 ISO 链接：

bash
bash reinstall.sh windows --iso=https://你的ISO链接 --image-name='Windows 10 Enterprise LTSC 2021'


### DD 脚本要注意的几点

- **重装前做快照**：DMIT 后台提供 1 个免费快照，装前先拍一个，出了问题可以回滚
- **数据会清空**：重装是完全覆盖安装，VPS 上的所有数据都会没，提前备份
- **低内存机型可能会卡**：内存低于 512MB 的机型跑 DD 脚本容易在安装中途卡住，建议优先用后台方式重装

## 常见问题

**Q：DMIT 后台重装系统会清数据吗？**

会。重装是全盘覆盖安装，VPS 上的所有文件和配置都会被清空。操作前一定要先备份数据，或者拍快照（后台提供 1 个免费快照位）。

**Q：重装完系统之后 SSH 密钥还能用吗？**

要看情况。如果在重装的时候选择了"保留现有密钥"，可以继续用原来的；如果是全新重装，需要重新下载或导入密钥。进后台 SSH 金钥管理页面操作。

**Q：DMIT 支持装 Windows 吗？**

官方后台的镜像列表里不是每个套餐都有 Windows 选项，如果没有可以用 DD 脚本方式自己装。需要自行准备 Windows 授权。

**Q：DMIT 后台的重装入口在哪里找不到怎么办？**

先确认 VPS 状态是关机（Stopped），开机状态下重装选项通常是灰色的或者不显示。关机之后刷新一下页面再找。如果还是找不到，发工单给客服，说明要重装系统，他们会指引操作或者帮你操作。

**Q：DMIT VPS 哪个套餐最适合新手入门？**

预算有限的话，洛杉矶 EB 系列配合年付优惠码性价比不错，CMIN2 线路对国内访问也够用。预算稍微宽松一些，Pro.TINY 或 Pro.Pocket 走 CN2 GIA，稳定性会更好。

**Q：优惠码可以和年付叠加吗？**

可以，也必须选季付或以上才能用大多数优惠码。月付一般不享受折扣，切换到季付或年付之后在结算页面填优惠码，点"校验代码"验证就好。
